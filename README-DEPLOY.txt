CARE DON'T CARRY CO. — NETLIFY DEPLOYMENT

1. In Netlify, open the site you want to use.
2. Deploy this ZIP by drag-and-drop, or connect the folder through your preferred Git workflow.
3. In Forms, confirm that "reminder-list" and "contact" were detected after deployment.
4. Test both forms with your own email address.
5. Test all five product buttons on desktop and mobile.
6. When ready, connect caredontcarryco.com to Netlify.
7. Optional later step: connect shop.caredontcarryco.com to the Printify Pop-Up Store.

The current product links intentionally use the existing Printify URL, so the site works before a domain purchase.
