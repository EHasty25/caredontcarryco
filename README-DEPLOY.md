# Care Don't Carry Co. — coastal homepage preview

This is a complete static replacement for the current GitHub/Netlify site. It needs no build command.

## Included

- Coastal founder hero on the homepage
- Care. Don't Carry. positioned as the flagship
- All four hats linked to their live Printify product pages
- A direct link to the full Printify storefront
- Shortened homepage copy
- The full existing manifesto, contact, privacy, and shipping/returns pages
- An honest Our Places placeholder page for future tagged customer photographs
- Existing Netlify configuration and forms

## Preview before production

Create a new GitHub branch named `homepage-coastal-preview`, upload the contents of this folder to that branch, and open a pull request into `main`. Do not merge it yet. Netlify should attach one Deploy Preview to the pull request.

The repository root is the publish directory (`.`), and no build command is needed.
